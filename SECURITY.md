# Security reporting

Please do not disclose a security vulnerability in a public issue. Use GitHub's [private vulnerability reporting form](https://github.com/amnicator/saltytrack-public/security/advisories/new) so the report can be reviewed privately.

Include the affected SaltyTrack website page or extension version, a description of the behavior, and steps to reproduce when possible. Do not include passwords, account data, or other people's personal information.

This repository hosts public information and feedback; SaltyTrack's website and extension are developed privately. Security reports about either product are welcome through the private form above.
